# Web Development Internship - Task 1
Responsive Landing Page

## Project Overview
This project is a responsive landing page created using HTML5 and CSS3 for a fictional web development company named WebCraft.

## Objective
The objective was to understand:
* HTML structure
* Semantic HTML
* CSS styling
* Flexbox
* CSS Grid
* Media queries
* Responsive design

## Features
* Responsive header
* Navigation menu
* Hero section
* CTA button
* Services section
* Three service cards
* Responsive layout
* Footer
* Social links
* Hover effects

## Technologies Used
* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* VS Code
* Chrome
* Live Server

## Project Structure
```text
Task-1/
│
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Open the `Task-1` folder in VS Code.
2. Open `index.html`.
3. Install/use Live Server.
4. Right-click `index.html`.
5. Select "Open with Live Server".
6. The website will open in Chrome.

## Responsive Design
Media queries are used to support:
* Desktop
* Tablet
* Mobile

## Learning Outcomes
* Built a clean, professional web interface from scratch.
* Mastered CSS Flexbox for 1-dimensional layouts like headers and footers.
* Mastered CSS Grid for 2-dimensional layouts like service cards.
* Ensured accessibility and fully responsive behavior using media queries, avoiding horizontal scroll issues on mobile screens.
